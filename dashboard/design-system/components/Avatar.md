# Avatar

Avatars filter tickets by assignee, like a Jira sprint board.

Only the developer is selected by default. Add one avatar labelled "Non assigné" with initials "?". The consumer provides initials, the full name as `label` and a colour dark enough for white initials. Selection is a toggle, so the list always shows at least the selected people.

An unselected avatar has a dashed border, a selected one a solid lavender border. The initials keep full contrast in both states.
