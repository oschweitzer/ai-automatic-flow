# Section

Sections group tickets by state and fold away.

Use four, in this order: En cours, En attente, À faire, Terminé. The first two open by default, the others closed, and the open state is remembered per project. Put a table inside. Rows that open the detail panel take `tf-clickable` and `aria-selected` when open. Ticket keys use `tf-key`, second lines `tf-sub`.
